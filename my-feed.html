Instagram doesn't allow this

Instagram has no API that returns a feed of posts from people you follow — not even for a personal app like this one. The closest real thing is Instagram's own "Following" filter, one tap away below.

Open Instagram
Once it opens: tap the Instagram wordmark at the top of the Home feed → choose Following. That switches you to a chronological feed of only the people you follow, straight from Instagram itself.

If you don't see that option, Instagram hasn't rolled it out to your account — there's no workaround on our end that wouldn't break their Terms of Service.
One-time setup — takes about 10 minutes
  1. Go to console.cloud.google.com and create a new project (any name).
  2. Under APIs & Services → Library, enable YouTube Data API v3.
  3. Under APIs & Services → OAuth consent screen, choose External, fill in the required fields, and add yourself as a test user.
  4. Under APIs & Services → Credentials → Create Credentials → OAuth client ID, choose type Web application.
  5. Under Authorized JavaScript origins, add the exact address this page is running at (e.g. http://localhost:8000 if you're serving it locally, or your GitHub Pages URL). Note: opening the file directly with file:// won't work — Google requires a real http/https origin, so serve it locally (python3 -m http.server in the folder works) or host it somewhere like GitHub Pages.
  6. Copy the Client ID it gives you and paste it below.
